# Mini Project Web Development

This project is a simple CRUD (Create, Read, Update, Delete) web application built using HTML, CSS, and JavaScript.

## Features
- Add student records
- View records in a table
- Update existing data
- Delete records
- Search records
- Data saved in browser localStorage

## Project Files
- `index.html` – page structure
- `style.css` – styling
- `script.js` – CRUD logic

## Run Locally
Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
